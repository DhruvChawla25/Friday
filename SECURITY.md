# Security Policy

Friday is built to be private by design: no network access, no accounts, and only local data. If you find a way to break that promise, please tell us privately.

## Reporting a vulnerability

Email **dhruvchawla2511@gmail.com** with:
- what you found and how to reproduce it,
- the Friday version (e.g. v0.2.0) and macOS version.

Please **do not open a public issue** for security problems. You will get a reply within 7 days, and credit in the release notes if you want it.

## In scope
- Any way Friday sends data off the Mac
- Friday reading more than documented in [docs/PRIVACY.md](docs/PRIVACY.md), e.g. message contents
- Memory file (`memory.txt`) exposure, or permissions being misused

## Supported versions
Only the latest release receives fixes.
